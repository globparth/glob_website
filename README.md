# Globriddge website

Static multi-page website, served by GitHub Pages from the root of the `main` branch.

- `index.html` and the other `.html` files are the pages.
- `style.css` holds all styles. `main.js` holds the animations, the globe and the settings.
- Edit `CONFIG`, `REVIEWS` and `TOOLS` at the top of `main.js` to set contact details, client reviews and the tool list.
- The client reviews are demo text and are labelled as such on the site. Replace them with real, permissioned feedback and set `demo` to `false`.
- If the site moves to a custom domain, update the address in each page's `<head>`, in `sitemap.xml` and in `robots.txt`.
